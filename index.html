지역·포인트 선택
금주·차주는 접속일 기준 월~일로 자동 계산합니다. 오늘 날짜는 강조하고 이미 지난 날짜는 흐리게 표시합니다.
포인트 표기: ‘시·군/구 · 실제 지명’ 방식으로 통일했습니다. 포인트 선택은 해당 해안의 조석·기상정보 조회 기준점을 고르는 기능이며, 해당 장소의 채취 허용을 의미하지 않습니다. 출입통제·어촌계 관리구역·채취규정은 조회일 기준으로 별도 확인합니다.
공식 데이터 연결본 · 조위는 국립해양조사원, 날씨·기온·풍속은 기상청 단기예보에서 조회합니다. 아직 연결하지 않은 항목은 임의값 없이 ‘확인필요’로 표시합니다.
